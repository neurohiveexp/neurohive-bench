# Сколько токенов стоят таблицы и события магазина

Замер для статьи Neurohive «Сколько стоит месяц работы с ИИ» (ноябрь 2026).

- `gen.py` генерирует вымышленные данные интернет-магазина (seed 42): 1 000 заказов в CSV, Markdown и JSON, 1 000 событий сайта в формате Kafka (JSONL), схему четырёх таблиц BigQuery и результат агрегирующего запроса на 200 строк. Данные пишутся в `data/` (в репозиторий не входят).
- `count_data.mjs` считает токены офлайн-токенизаторами: o200k (GPT), Gemma 3, DeepSeek V4, Qwen3. Пакеты — как в `experiments/tokenizers` (`npm i gpt-tokenizer @lenml/tokenizer-gemma3 @lenml/tokenizer-deepseek_v4 @lenml/tokenizer-qwen3`).
- `results.json` — результат на 3 ноября 2026.

```
python3 gen.py
node count_data.mjs
```

| Данные | o200k | Gemma 3 | DeepSeek V4 | Qwen3 |
|---|---|---|---|---|
| 1 000 заказов, CSV | 51 346 | 78 105 | 56 048 | 78 691 |
| Те же заказы, JSON | 101 585 | 131 074 | 108 464 | 128 749 |
| 1 000 событий, JSONL | 165 294 | 205 336 | 171 258 | 197 236 |
| Схема 4 таблиц | 346 | 418 | 419 | 364 |

Токенизатора Claude в открытом доступе нет; для Claude и Gemini в статье использованы коэффициенты из замера TokenSave (таблица в CSV: Claude 913, Gemini 777, GPT 629 токенов).
