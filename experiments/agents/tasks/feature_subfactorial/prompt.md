Добавь в библиотеку more-itertools новую публичную функцию `subfactorial(n)`.

Что она делает: возвращает число перестановок из `n` элементов без неподвижных точек (субфакториал, OEIS A000166), то есть ровно `ilen(derangements(range(n)))`, но считает его напрямую, без перебора.

Требования:

- `subfactorial(0) == 1`, `subfactorial(1) == 0`, `subfactorial(2) == 1`, `subfactorial(7) == 1854`; результат точный (целое число Python) и для больших `n`, например `subfactorial(23) == 9510425471055777937262`.
- Отрицательное `n` → `ValueError`. Нецелое `n` (например, `5.0` или `'5'`) → `TypeError`.
- Функция доступна как `more_itertools.subfactorial`: добавь её в `__all__`, в заглушку типов `more_itertools/more.pyi` и в документацию `docs/api.rst`.
- Напиши docstring с примером и юнит-тесты в `tests/test_more.py`.
- Существующие тесты должны проходить.
