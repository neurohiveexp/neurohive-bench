Исправь баг в `more_itertools.bucket` (issue #1284 в репозитории more-itertools).

Описание бага: неудачная проверка наличия ключа добавляет «фантомный» ключ.

```python
>>> from more_itertools import bucket
>>> s = bucket([10, 20, 11, 21], key=lambda x: 10 * (x // 10))
>>> sorted(s)
[10, 20]
>>> 30 in s
False
>>> sorted(s)          # ожидается [10, 20]
[10, 20, 30]
```

То же происходит после `list(s[30])` для отсутствующего ключа и при переданном `validator`, который пропускает ключ 30. Итерация по `bucket` должна возвращать только ключи, для которых в исходной последовательности встретился хотя бы один элемент. Ключ, все элементы которого уже выбраны через `s[key]`, должен по-прежнему перечисляться.

Исправь код и добавь регрессионные тесты в `tests/test_more.py`. Существующие тесты должны проходить.
