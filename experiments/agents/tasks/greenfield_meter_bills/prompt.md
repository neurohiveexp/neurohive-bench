Напиши с нуля маленькое консольное приложение на Python 3.10+ (только стандартная библиотека): расчёт платы за воду по показаниям счётчиков для управляющей компании города Верхнедольска.

Файл программы: `meter.py` в корне репозитория. Запуск: `python meter.py <команда> ...`.

## Входные данные

CSV в UTF-8 с заголовком `apartment,date,cold,hot`:

- `apartment` — номер квартиры, строка (например, `12` или `12А`);
- `date` — дата снятия показаний в формате `ГГГГ-ММ-ДД`;
- `cold`, `hot` — показания счётчиков холодной и горячей воды в м³, десятичная точка, до 3 знаков после неё.

Строки могут идти в любом порядке.

## Команда `bill`

`python meter.py bill <файл.csv> --month ГГГГ-ММ --cold-rate <руб/м³> --hot-rate <руб/м³>`

Для каждой квартиры расход за месяц = последнее показание в этом месяце минус последнее показание в любом из предыдущих месяцев (отдельно для холодной и горячей воды). Квартиры без показаний в указанном месяце или без показаний до него в отчёт не попадают.

Сумма = расход холодной × тариф холодной + расход горячей × тариф горячей, округление до копеек по правилу «половина вверх» (0,005 → 0,01). Считай в `decimal.Decimal`, не во `float`.

Вывод в stdout: по одной строке на квартиру, отсортировано по номеру квартиры как по строке, поля через табуляцию:

```
<квартира>\t<расход холодной, 3 знака>\t<расход горячей, 3 знака>\t<сумма, 2 знака>
```

Последняя строка: `ИТОГО\t<сумма всех квартир, 2 знака>`. Если квартир нет, выводится только `ИТОГО\t0.00`.

## Ошибки

- Если у квартиры показание меньше предыдущего по дате (по холодной или горячей воде), программа печатает в stderr строку, содержащую `ошибка` и номер квартиры, и завершается с кодом 2, ничего не выводя в stdout.
- Нечитаемая строка CSV (не хватает полей, дата или число в неверном формате) — тоже код 2 и сообщение в stderr с номером строки файла (заголовок — строка 1).
- Несуществующий файл — код 2.
- Успешный запуск — код 0.
