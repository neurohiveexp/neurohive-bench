# Калькулятор стоимости API нейросетей

Одностраничный калькулятор: один файл `index.html` на чистом JS, без зависимостей и сборки. Тарифы лежат в `prices.json`.

Что считает:

- **стоимость месяца по каждой модели** для трёх готовых сценариев. Все параметры сценариев можно менять:
  - разработчик с ИИ-агентом: 2 часа в день, 22 рабочих дня в месяц;
  - поддержка интернет-магазина: 5000 обращений в месяц на русском;
  - аналитик: 100 PDF по 40 страниц в месяц;
- **точку безубыточности подписок за $20 и $200**: сколько запросов в месяц (и токенов в день) нужно, чтобы API стоил как подписка;
- **когда своя RTX 4090 дешевле API**: порог в токенах в день. Цена карты, срок амортизации (по умолчанию 3 года), тариф на электричество в ₽/кВт·ч, курс, потребление и скорость модели вводятся вручную.

Стоимость запроса считается по той же формуле, что `bench/cost.py`: кешированные токены идут по цене кеша, а если входных токенов строго больше порога `long_threshold`, цены входа и выхода умножаются на `long_input_mult` и `long_output_mult`. Цена кеша при этом не меняется. Результат округляется до 6 знаков.

Текущие параметры попадают в адрес страницы (`#s=support&tickets=20000`), поэтому ссылкой на расчёт можно поделиться.

## Файлы

| Файл | Назначение |
| --- | --- |
| `index.html` | Калькулятор целиком: разметка, стили, формула, сценарии |
| `prices.json` | Тарифы: модель, вход, выход, кеш, порог длинного запроса и коэффициенты, дата, ссылка на источник, `verified` |
| `sync-prices.mjs` | Копирует `prices.json` в запасной блок внутри `index.html` |
| `test.mjs` | Тесты на node |

## Тарифы

Цены указаны в USD за 1 млн токенов. **Все тарифы в `prices.json` — примеры с пометкой «сверить перед публикацией» (`"verified": false`).** Пока хотя бы у одной модели стоит `false`, калькулятор показывает предупреждение. Перед публикацией:

1. Сверьте цены, порог и коэффициенты с официальной страницей провайдера (поле `source`), обновите `date` и поставьте `"verified": true`.
2. Удалите условную модель `example-long-context`: это тариф из тестов задачи `code_cost`, а не реальная модель.
3. Скопируйте тарифы в `index.html`:

```bash
node tools/cost-calculator/sync-prices.mjs
```

На сайте калькулятор загружает `prices.json`, который лежит рядом с ним. Копия внутри `index.html` нужна, если файл открыт без сервера (`file://`) или `prices.json` не загрузился.

## Тесты

```bash
node --test tools/cost-calculator/test.mjs
```

Тесты проверяют:

- формулу из `index.html` на всех примерах из `tasks/code_cost/tests.py`;
- совпадение с `bench/cost.py` на 2000 случайных запросов (если установлен `python3`);
- формат `prices.json` и то, что копия тарифов в `index.html` с ним совпадает;
- расчёт сценариев и точек безубыточности.

## Как встроить в WordPress через iframe

### 1. Выложите файлы

Калькулятору нужны `index.html` и `prices.json` в одной папке. WordPress по умолчанию не разрешает загружать `.html` в медиатеку, поэтому подойдёт один из вариантов:

- **на тот же сервер:** скопируйте папку по SFTP, например в `/wp-content/uploads/tools/cost-calculator/`. Калькулятор будет открываться по адресу `https://neurohive.io/wp-content/uploads/tools/cost-calculator/`;
- **на GitHub Pages:** включите Pages для репозитория. Калькулятор будет доступен по адресу вида `https://<владелец>.github.io/neurohive-bench/tools/cost-calculator/`.

Лучше выложить на свой домен: так ссылки и поисковый вес остаются у сайта. Проверьте, что адрес открывается в браузере и внизу таблицы «Тарифы» видны актуальные даты.

### 2. Вставьте iframe на страницу

В редакторе блоков добавьте блок «Произвольный HTML» и вставьте код. Замените `src` на свой адрес:

```html
<iframe
  id="nh-cost-calculator"
  src="https://neurohive.io/wp-content/uploads/tools/cost-calculator/"
  title="Калькулятор стоимости API нейросетей"
  loading="lazy"
  style="width:100%;height:2600px;border:0;display:block"
></iframe>
<script>
  // Калькулятор сообщает свою высоту, чтобы на странице не было второй полосы прокрутки.
  window.addEventListener("message", function (e) {
    var frame = document.getElementById("nh-cost-calculator");
    if (!frame || e.source !== frame.contentWindow) return;
    if (e.data && e.data.type === "nh-cost-calculator:height") {
      frame.style.height = Math.ceil(e.data.height) + 20 + "px";
    }
  });
</script>
```

Замечания:

- WordPress сохраняет `<script>` в блоке «Произвольный HTML» только у администраторов (право `unfiltered_html`). Если скрипт вырезается, оставьте только `<iframe>` с фиксированной высотой: около `2600px` для компьютера и `4600px` для телефона. Либо подключите скрипт через тему или плагин вроде WPCode.
- Чтобы открыть калькулятор сразу на нужном сценарии, добавьте к адресу параметры, например `.../cost-calculator/#s=analyst` или `#s=support&tickets=20000`.
- Тёмная тема включается по настройке системы. Чтобы зафиксировать светлую тему, добавьте `data-theme="light"` в тег `<html>` в `index.html`.
- Если калькулятор лежит на другом домене, проверьте, что сервер не отдаёт заголовки `X-Frame-Options: DENY` или `Content-Security-Policy: frame-ancestors`, которые запрещают встраивание.

### 3. Ссылочный актив

Под iframe стоит добавить текстовое описание сценариев и формулы: поисковики почти не индексируют содержимое iframe. Также дайте прямую ссылку на калькулятор, чтобы его было удобно цитировать.
