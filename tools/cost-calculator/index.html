3. Своя RTX 4090 против API

Видеокарта окупается, когда экономия на каждом запросе покрывает амортизацию и электричество. Скорости по умолчанию — ориентир для модели ~27–32B в 4-битной квантизации; локальная модель по качеству может уступать облачной.

Как считается

Постоянные расходы в день = цена карты / (срок амортизации × 365) + мощность в простое × часы работы × тариф. Переменные на запрос = (мощность под нагрузкой − в простое) × время запроса × тариф, где время = некешированный вход / скорость обработки + выход / скорость генерации. Точка безубыточности = постоянные расходы / (цена запроса в API − переменные расходы на запрос). Если порог больше, чем карта успевает обработать за часы работы, она не окупается.
