- `"input"` — входные токены без кеша;
- `"cached"` — входные токены, прочитанные из кеша;
- `"output"` — выходные токены;
- необязательные ключи `"long_threshold"`, `"long_input_mult"` и `"long_output_mult"` — надбавка за длинный запрос (если есть один из них, есть и остальные два).

Правила:
1. `cached_tokens` — часть `input_tokens`. Обычные входные токены = `input_tokens - cached_tokens`.
2. Если в `price` есть `"long_threshold"` и `input_tokens` строго больше него, цена обычных входных токенов умножается на `long_input_mult`, а цена выходных — на `long_output_mult`. Цена кешированных токенов не меняется.
3. Если какое-то количество токенов отрицательное или `cached_tokens > input_tokens`, функция бросает `ValueError`.
