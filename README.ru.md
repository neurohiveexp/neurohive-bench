# Базовый набор задач Neurohive (v1)

12 небольших задач с автоматической проверкой. [neurohive.io](https://neurohive.io) использует их в собственных тестах моделей: локальные модели против облачных, цена решённой задачи, ИИ-агенты, слепой тест на русском. Один общий набор делает результаты разных статей сравнимыми, а любой читатель может перепроверить наши цифры.

[English version](README.md)

## Задачи

| ID | Категория | Язык | Что проверяет |
| --- | --- | --- | --- |

| `ru_letter` | text_ru | ru | Письмо-претензия, в котором сохранены все 10 фактов, до 220 слов |
| `ru_edit` | text_ru | ru | Исправить 9 ошибок, не переписывая текст |
| `ru_qa` | text_ru | ru | Ответы по тексту о тарифах: расчёт с ловушкой и честное «нет данных» |
| `en_summary` | text_en | en | Пересказ в одном предложении до 35 слов |
| `en_translate` | text_en | en | Перевод с русского на английский по глоссарию |
| `code_parse_date` | code | ru | Разбор русских дат на Python, скрытые тесты |
| `code_bugfix` | code | ru | Исправить 5 ошибок в двух функциях пагинации |
| `code_cost` | code | ru | Стоимость запроса к API с кешем и надбавкой за длинный запрос |
| `json_receipts` | json | ru | Четыре чека → JSON (ловушки: сдача вместо суммы, юрлицо вместо магазина, дата 15/10/26) |

Все тексты оригинальные и вымышленные (город Верхнедольск, порт Халвик, Larkspur Labs), поэтому модель не может знать ответы заранее.

## Как проверяется

Правила каждой задачи лежат в `tasks/<id>/task.json`. Задача решена, только если выполнены все её правила. ИИ-судьи нет.

- **Тексты:** лимиты слов и пунктов, обязательные факты, алфавит, конкретные исправления, сходство с эталоном.
- **Код:** код из ответа запускается со скрытыми тестами `tasks/<id>/tests.py`.
- **JSON:** разбирается и сравнивается с `reference.json` по полям.
- **Логика и вопросы:** числа в заданном формате ответа.

Правила проверяют факты, формат и ограничения, но не стиль. Стиль оценивают люди, как в нашем слепом тесте.

## Как запустить

Нужен Python 3.10+, сторонние библиотеки не нужны.

```bash
# ID моделей и цены ниже — примеры: точные значения берите у провайдера в день теста
python -m bench list

# любой OpenAI-совместимый API: OpenAI, OpenRouter, DeepSeek, vLLM, Ollama, llama.cpp, LM Studio
export NH_API_KEY=...
python -m bench run --base-url https://openrouter.ai/api/v1 --model deepseek/deepseek-v4.1-flash \
  --runs 3 --price-input 0.15 --price-output 0.60 --price-cached 0.03

# локальная модель без ключа
python -m bench run --base-url http://localhost:11434/v1 --model qwen3.8:27b --api-key-env ""

python -m bench report --out report.md
```

Цены указываются в долларах за 1 млн токенов на день теста, сверять по странице провайдера. Если модель не принимает `temperature`, укажите `--temperature none`.

**Веб-чаты без API (Алиса AI, GigaChat и другие):**

1. Выполните `python -m bench prompts --out prompts` и вставьте каждый промпт в чат.
2. Сохраните ответ в `responses/<название>/<task_id>.txt`.
3. Выполните `python -m bench score responses/<название> --model "<версия из чата>"`.

## Результаты и метрики

- В `results/<название>/<время>.jsonl` пишется по одной строке на каждый прогон задачи: ответ, вердикт, детали проверки, токены, время, стоимость.
- **Задача решена**, если она прошла в большинстве прогонов.
- **Цена прошедшего прогона:** все потраченные деньги, включая неудачные прогоны, делённые на число успешных. Это «цена решённой задачи» из наших статей.

## Инструменты

[`tools/cost-calculator`](tools/cost-calculator/) — одностраничный калькулятор стоимости API за месяц для трёх типовых сценариев. Он показывает точку безубыточности подписок за $20 и $200 и своей RTX 4090. Формула та же, что в `bench/cost.py`; тесты: `node --test tools/cost-calculator/test.mjs`.

## Безопасность

Задачи на код запускают код, написанный моделью, в отдельном процессе с ограничением по времени. Запускайте набор в контейнере или виртуальной машине, не на компьютере с секретами. Используйте отдельный API-ключ с лимитом расходов.

## Версии

Опубликованные задачи не редактируются. Исправление или новая задача — это новая версия задачи и набора (`v2`) с записью в [CHANGELOG.md](CHANGELOG.md). В статьях указываем, какой версией пользовались.
